# Heritage & Culture 🇮🇳

A static website that explores India's rich heritage, historical monuments, festivals, and cultural traditions.

## 🌐 Overview

**Heritage & Culture** is a beginner-friendly web development project created using HTML and CSS. It highlights India's cultural diversity through informative sections, images, and an attractive user interface.

## ✨ Features

- Homepage with a hero section
- Featured Indian heritage destinations
- Famous Indian festivals
- Art and cultural traditions
- Responsive layout for different screen sizes
- Font Awesome icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the website.

## 🎯 Project Purpose

This project was developed as a university web development project to practice HTML and CSS, understand website structure, and create an informative website about Indian heritage and culture.
